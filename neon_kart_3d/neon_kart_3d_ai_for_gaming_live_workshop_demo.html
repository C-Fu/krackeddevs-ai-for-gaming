How this prototype connects to Antigravity, OpenCode & Blender

1. Start Blender MCP Server
uvx mcp-for-blender

Connects Antigravity / OpenCode to Blender 3D Viewport to build low-poly karts & export public/assets/models/kart.glb.

2. Local Prototype Audio (`yt-dlp`)
yt-dlp -x --audio-format mp3 <YOUTUBE_URL> -o "public/assets/bgm.mp3"

Pulls temporary local lab BGM; swap with Suno AI or CC0 tracks before pushing to GitHub Pages.

3. Static Web Deploy (Zero DB)
npm run build && npx vercel --prod

Deploys static dist/ bundle to GitHub Pages, Netlify Drop, or Vercel in 30s.
