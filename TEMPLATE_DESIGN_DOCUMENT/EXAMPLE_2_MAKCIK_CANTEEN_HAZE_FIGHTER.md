# Example Game Spec: Makcik Canteen — Haze Fighter

*[Live Game Demo](../MAKCIK_CANTEEN/index.html) | [Game Folder](../MAKCIK_CANTEEN/) | [Copilot Live Session](https://copilot.microsoft.com/conversations/join/NppskzM778rkVNxfjVi5D)*

## 1. High Concept & Overview
- **Title:** *Haze Fighter (Makcik Canteen vs Jerebu)*
- **Genre:** 3D Action Arcade
- **Platform:** Web Browser (Babylon.js 7, Web Audio API, Zero Backend)
- **Target Persona:** High school students (Ali, 16, SMK Sri Bangsar / Alam Shah Science School).
- **Premise (Point A to Point B):** Recess starts in 60 seconds! An unhealthy haze cloud (API 385+) has invaded the canteen. Clear all 24 haze clusters before the school bell rings.

## 2. Core USPs
- **USP 1: Industrial Blower Fan (`Spacebar` / Right-Click):** Continuous 42° wind cone that applies continuous repulsive physics and dissolves haze clusters.
- **USP 2: Cryogenic Dry Ice Bombs (`Left-Click` / `E Key`):** Ballistic arc projectile with expanding frost shockwave AOE that obliterates haze clusters.
- **Atmospheric Smoke Clearing:** As haze is cleared, the suffocating yellow-brown room smog lifts dynamically into bright crisp daylight!
